EPA Monitor and USA Cities GIS Application

This project is a continuation of my work with Dr. Guofeng Cao.

The EPA monitors numerous pollutants throughout the US. This map is meant to depict the spatial distribution of the EPA's monitoring locations. Overlayed are cities with a population greater than 100,000.

Click a state to zoom to it. Select a set of points with the tool on the left. Legend and more layer controls are coming soon!
